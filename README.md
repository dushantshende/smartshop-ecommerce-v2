# SmartShop V2

A professional E-Commerce application developed using Java,
Spring Boot, REST APIs, MySQL, and Angular.

## Technology Stack

- Java 17
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- Spring Security
- JWT Authentication
- Angular
- Git and GitHub

## Core Features

- User Registration and Login
- Role-Based Access Control
- Product Management
- Shopping Cart
- Order Management
- Purchase History
- Inventory Management
